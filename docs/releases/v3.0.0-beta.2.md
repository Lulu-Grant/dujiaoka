# 独角数卡西瓜版 v3.0.0-beta.2 发布说明

发布日期：2026-06-01

版本定位：

- Laravel 7 桥接实验验收版本。
- 不直接升级到 Laravel 8/10 或 PHP 8.5。
- 重点是固定 PHP 7.4 / PHP 8.1 双运行时可验证依赖组合、Dcat 兼容层职责和保留支付通道安全护栏。

## 本版变化

- Laravel 从 6.20 桥接到 `7.30.7`，并保持 PHP 7.4 / PHP 8.1 双运行时测试可通过。
- 固定 Composer 兼容约束：`config.platform.php=7.4.33`、`ramsey/uuid ^3.9`、`psr/log ^1.1`，避免 PHP 8-only 依赖进入 PHP 7.4 验收链。
- 补强 Dcat 最小兼容层审计和测试，明确不删除 `config/admin.php`、不删除 `routes/admin/routes.php`。
- 补强未登录访问后台壳路径的登录跳转测试。
- 继续保持退役支付通道防回流：PayPal、Stripe、Coinbase、Mapay、TokenPay、PayJS、Vpay、Paysapi 不恢复。
- 更新 README、当前基线、进度总汇、升级阻塞矩阵和 release 文档到 `417 tests / 4281 assertions` 基线。

## 当前工具链状态

- `scripts/composer74` 优先使用 `COMPOSER74_BIN`。
- 未设置 `COMPOSER74_BIN` 时，默认使用 `tools/composer-2.2.phar`。
- 系统 Composer 只作为最后回退。
- `./scripts/composer74 --version` 当前输出 `Composer version 2.2.25`。
- `scripts/composer81-docker` 使用同一个项目内 Composer 2.2 phar。
- PHP 8.1 Web smoke 使用 Docker 内置 Web 服务临时启动，验证后必须停止容器。

## 发布边界

- 不直接升级 Laravel / PHP 大版本。
- 不删除 Dcat 兼容关键文件。
- 不恢复已退役支付通道。
- 不新增高风险后台批量动作。
- 不修改支付回调 URL 语义。

## 失败回滚条件

- Composer 安装失败或锁文件不可重复。
- Laravel 启动期因 Dcat、Yansongda 或旧 helper 直接崩溃。
- migration 状态检查失败。
- 全量 PHPUnit 或后台 smoke 失败。
- 需要直接跳 Laravel / PHP 大版本才能继续。
