# 独角数卡西瓜版 v3.0.0-beta.2 规划

发布日期：待定

版本定位：

- 升级实验准备版本
- 不直接升级 Laravel / PHP 大版本
- 重点是依赖阻塞、支付 SDK 边界和实验分支验证清单

## 必须满足的状态

- beta.1 已冻结并通过全量 PHPUnit 与后台壳 smoke。
- 依赖阻塞矩阵刷新完成。
- PayPal 旧 SDK 当前决策为“保留过渡，准备替换或退场”，只允许通过 `PaypalGatewayClientInterface` / `PaypalSdkService` 边界访问。
- Stripe 继续保持 `20.x` 基线，服务边界稳定。
- 升级实验分支最小命令集可执行。
- PHP 7.4 Composer 工具链已固定到项目内 Composer 2.2 phar，避免系统 Composer 版本漂移。

## 升级实验命令集

```bash
./scripts/composer74 install
./scripts/php74 artisan migrate:status
./scripts/php74 vendor/bin/phpunit
ADMIN_USERNAME=admin-shell-tester ADMIN_PASSWORD=secret123 ./scripts/smoke-admin-shell
```

## 当前工具链状态

- `scripts/composer74` 优先使用 `COMPOSER74_BIN`。
- 未设置 `COMPOSER74_BIN` 时，默认使用 `tools/composer-2.2.phar`。
- 系统 Composer 只作为最后回退。
- `./scripts/composer74 --version` 当前输出 `Composer version 2.2.25`。

## 失败回滚条件

- Composer 安装失败或锁文件不可重复。
- Laravel 启动期因 Dcat、PayPal、Stripe、Yansongda 或旧 helper 直接崩溃。
- migration 状态检查失败。
- 全量 PHPUnit 或后台 smoke 失败。
- 需要直接跳 Laravel / PHP 大版本才能继续。

## 不纳入 beta.2 的事项

- 不直接跳 Laravel 大版本。
- 不删除 Dcat 兼容关键文件。
- 不恢复已退役支付通道。
- 不新增高风险后台批量动作。
