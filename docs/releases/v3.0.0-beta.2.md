# 独角数卡西瓜版 v3.0.0-beta.2 规划

发布日期：待定

版本定位：

- 升级实验准备版本
- 不直接升级 Laravel / PHP 大版本
- 重点是依赖阻塞、支付 SDK 边界和实验分支验证清单

## 必须满足的状态

- beta.1 已冻结并通过全量 PHPUnit 与后台壳 smoke。
- 依赖阻塞矩阵刷新完成。
- PayPal 旧 SDK 有保留 / 替换 / 退场决策。
- Stripe 继续保持 `20.x` 基线，服务边界稳定。
- 升级实验分支最小命令集可执行。

## 不纳入 beta.2 的事项

- 不直接跳 Laravel 大版本。
- 不删除 Dcat 兼容关键文件。
- 不恢复已退役支付通道。
- 不新增高风险后台批量动作。
