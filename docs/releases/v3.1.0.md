# 独角数卡西瓜版 v3.1.0 发布说明

发布日期：2026-06-01

版本定位：

- PHP 8.1 / Laravel 8 稳定锚点。
- `v3.0.0` 保持为 Laravel 7 回滚锚点。
- Dcat 继续作为后台登录、认证、中间件、权限白名单和旧入口兼容层。
- 不新增支付通道，不删除 Dcat 兼容关键入口，不修改支付回调 URL 语义。

## 当前状态

| 项目 | 当前状态 |
| --- | --- |
| Runtime | PHP 8.1+ |
| Framework | Laravel `8.83.29` |
| PHPUnit | `OK (417 tests, 4299 assertions)` |
| CI | GitHub Actions `CI` 使用 PHP 8.1 主验证并通过 |
| 后台 smoke | PHP 8.1 Web 路径已通过 |
| 支付范围 | 官方支付宝、官方微信、易支付、Epusdt |
| Dcat | 保留过渡兼容层 |

## 稳定版边界

- `3.x` 继续保留 `/admin`、`/admin/auth/login`、`/admin/auth/setting` 和 `/admin/v2/*`。
- 旧 `/admin/*` 兼容跳转继续保留 query string。
- `config/admin.php` 和 `routes/admin/routes.php` 不在 `v3.1.0` 删除。
- PayPal、Stripe、Coinbase、Mapay、TokenPay、PayJS、Vpay、Paysapi 不恢复。
- Laravel 10+、Dcat 退场和 abandoned 依赖替换进入后续独立分支。
