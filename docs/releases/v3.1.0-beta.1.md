# 独角数卡西瓜版 v3.1.0-beta.1 发布说明

发布日期：2026-06-01

版本定位：

- PHP 8.1 / Laravel 8 主线第一版。
- `v3.0.0` 保持为 Laravel 7 回滚锚点。
- Dcat 继续作为后台登录、认证、中间件、权限白名单和旧入口兼容层。
- 不新增支付通道，不删除 Dcat 兼容关键入口，不修改支付回调 URL 语义。

## 当前状态

| 项目 | 当前状态 |
| --- | --- |
| Runtime | PHP 8.1+ |
| Framework | Laravel `8.83.29` |
| PHPUnit | `OK (417 tests, 4292 assertions)` |
| CI | GitHub Actions `CI` 使用 PHP 8.1 主验证 |
| 后台 smoke | PHP 8.1 Web 路径已通过 |
| 支付范围 | 官方支付宝、官方微信、易支付、Epusdt |
| Dcat | 保留过渡兼容层 |

## 关键变化

- Composer `php` 约束切到 `^8.1`。
- `laravel/framework` 升级到 `^8.83`。
- `ramsey/uuid` 升级到 4.x。
- `vlucas/phpdotenv` 升级到 5.6.x。
- `dragonmantank/cron-expression` 升级到 3.x。
- CI 移除 PHP 7.4 job，只保留 PHP 8.1 主验证。
- `scripts/prepare-test-db` 默认通过 PHP 8.1 Docker 路径准备测试库。

## 保留边界

- 不删除 `config/admin.php`。
- 不删除 `routes/admin/routes.php`。
- 不恢复 PayPal、Stripe、Coinbase、Mapay、TokenPay、PayJS、Vpay、Paysapi。
- 不新增后台批量动作。
- 不修改支付回调 URL 语义。
