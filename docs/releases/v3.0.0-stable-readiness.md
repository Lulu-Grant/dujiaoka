# 独角数卡西瓜版 v3.0.0 稳定版前置清单

发布日期：待定

## 稳定版发布前要求

- 本地全量 PHPUnit 通过。
- 后台壳 smoke 通过。
- CI 通过。
- `git diff --check` 通过。
- release 文档标明仍保留的遗留边界。
- 安全专项清单无未解释高风险项。
- 支付异常路径测试覆盖重复通知、签名失败、金额不一致和已完成订单重复推进。
- 升级实验状态明确，不把实验分支内容混入稳定版。

## 稳定版前不接受

- 新支付通道。
- 新高风险批量动作。
- Laravel / PHP 大版本升级。
- 删除 Dcat 兼容关键入口。

## 发布说明必须包含

- 当前运行时基线。
- 后台壳覆盖范围。
- 保留的 Dcat 兼容职责。
- 支付通道生命周期状态，明确只保留官方支付宝、官方微信、易支付和 Epusdt。
- 已知升级阻塞和后续升级实验计划。

## 最终验证命令

```bash
git diff --check
./scripts/php74 vendor/bin/phpunit
ADMIN_USERNAME=admin-shell-tester ADMIN_PASSWORD=secret123 ./scripts/smoke-admin-shell
```
