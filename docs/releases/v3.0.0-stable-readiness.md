# 独角数卡西瓜版 v3.0.0 稳定版前置清单

发布日期：待定

## 稳定版发布前要求

- 本地全量 PHPUnit 通过。
- 后台壳 smoke 通过。
- CI 通过。
- `git diff --check` 通过。
- release 文档标明仍保留的遗留边界。
- 安全专项清单无未解释高风险项。
- 支付异常路径测试覆盖重复通知、签名失败、金额不一致和已完成订单重复推进。
- 升级实验状态明确，不把实验分支内容混入稳定版。

## 当前 stable-ready 状态

| 项目 | 当前状态 | 证据 |
| --- | --- | --- |
| 本地 PHPUnit | 已通过，当前基线为 `OK (400 tests, 2625 assertions)` | README、当前基线审计、当前进度总汇、执行基线 |
| 后台 smoke | 已通过，且必须显式传入本地开发或测试专用后台账号 | `tests/Browser/admin-shell-smoke.sh`、本地 smoke 凭据边界测试 |
| `git diff --check` | 已通过 | RC.1 本地验证记录 |
| CI | 仍需以最终发版分支上的 GitHub Actions 为准 | 稳定版发布前必须复查 |
| 安全专项 | 默认账号、密钥、输入面、测试凭据、secret scanning 风险和支付回调异常路径均有状态记录 | 安全基线审计、release 文档测试 |
| 支付通道 | 只保留官方支付宝、官方微信、易支付、Epusdt | 支付通道整改清单、退役通道防回流测试 |
| 升级实验 | beta.2 只保留实验命令集和阻塞矩阵，不混入稳定版 | 依赖阻塞矩阵、beta.2 release 文档 |

## 保留的遗留边界

| 边界 | stable-ready 处理 |
| --- | --- |
| PHP / Laravel | 当前运行时基线仍是 PHP 7.4 + Laravel 6.20，不在稳定版前直接跳大版本 |
| Dcat Admin | 保留登录、认证、中间件、权限白名单和旧 `/admin/*` 入口兼容，不删除 `config/admin.php` 和 `routes/admin/routes.php` |
| Dcat easy-excel | 保留过渡，随后台壳导入导出能力成熟后再替换 |
| Yansongda Pay | 继续服务官方支付宝 / 官方微信，先以回调异常路径测试约束 |
| Composer abandoned 包 | `swiftmailer/swiftmailer`、`symfony/debug` 仍作为后续替换观察项 |
| 退役支付通道 | PayPal、Stripe、Coinbase、Mapay、TokenPay、PayJS、Vpay、Paysapi 不恢复 |

## 稳定版前不接受

- 新支付通道。
- 新高风险批量动作。
- Laravel / PHP 大版本升级。
- 删除 Dcat 兼容关键入口。

## 发布说明必须包含

- 当前运行时基线。
- 后台壳覆盖范围。
- 保留的 Dcat 兼容职责。
- 支付通道生命周期状态，明确只保留官方支付宝、官方微信、易支付和 Epusdt。
- 已知升级阻塞和后续升级实验计划。
