# 独角数卡西瓜版 v3.3.0 发布说明

发布日期：2026-06-03

版本定位：

- PHP 8.1 / Laravel 8.83 主线上的稳定维护版本。
- `v3.2.0` 前台资源拆包发布候选已并入稳定口径。
- `v3.3.0` 固化支付与安全护栏矩阵，不新增公开 API，不修改下单、订单查询、支付跳转或支付回调语义。
- 后续 Laravel 10+、Dcat 退场和 abandoned 依赖替换继续保持单独实验分支。

## 稳定版边界

- `3.x` 继续保留 `/admin`、`/admin/auth/login`、`/admin/auth/setting` 和 `/admin/v2/*`。
- 旧 `/admin/*` 入口继续通过兼容层跳转到后台壳，并保留 query string。
- [config/admin.php](/Users/apple/Documents/dujiaoshuka/config/admin.php) 和 [routes/admin/routes.php](/Users/apple/Documents/dujiaoshuka/routes/admin/routes.php) 不在本版本删除。
- PayPal、Stripe、Coinbase、Mapay、TokenPay、PayJS、Vpay、Paysapi 不恢复。
- 不新增支付 SDK，不修改 `pay-gateway/{handle}/{payway}/{orderSN}`、支付回调 URL 或订单完成语义。

## 前台资源状态

`avatar` 前台新页面已停止加载：

- `vendor.min.js`
- `app.min.js`
- `bootstrap-input-spinner.js`
- `icons.min.css`
- `bootstrap.min.js`
- `bootstrap.min.css`

旧静态文件继续保留，用于历史页面、回滚兼容和后续审计。本版本只冻结前台新页面引用，不删除历史资源。

## 支付与安全护栏

- 保留支付通道固定为官方支付宝、官方微信、易支付和 Epusdt。
- 退役通道继续由 deny-list、前台支付列表过滤、支付入口拒绝、后台支付入口校验和样例 seed 护栏约束。
- 回调异常路径保持测试维护状态：签名失败、重复通知、金额不一致、订单不存在、支付方式不匹配和已完成订单重复通知。
- 默认账号、默认密钥、安装默认值、支付配置、后台批量动作、上传、模板输入、邮件发送和通知配置按 [v3.3 支付与安全护栏矩阵](/Users/apple/Documents/dujiaoshuka/docs/v3.3-payment-security-guardrail-matrix.md) 继续维护。
