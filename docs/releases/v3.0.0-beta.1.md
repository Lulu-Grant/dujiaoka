# 独角数卡西瓜版 v3.0.0-beta.1 候选清单

发布日期：待定

版本定位：

- 第二阶段现代化预发布候选
- 面向后台壳主承载、支付安全、安全治理和升级前清障的集中验收
- 仍不是长期稳定正式版，不建议跳过本地验证直接用于生产

## beta.1 必须满足的状态

- 后台壳日常运营动作基本可用，`goods / order / pay / coupon / carmis` 高频资源继续保持低风险动作边界。
- Dcat Admin 只作为登录、认证、中间件和旧入口兼容层存在，不再新增业务承载。
- 支付关键异常路径有测试护栏，覆盖重复通知、签名失败、金额不一致和已完成订单重复推进。
- 安全专项有清单和处理状态，覆盖后台批量动作、导入、配置编辑、账号设置、上传、模板输入、邮件发送和通知配置。
- 升级阻塞矩阵已刷新，并具备升级实验分支最小验证命令集。

## 当前候选重点

- 卡密管理继续补齐导入后维护动作，新增批量追加卡密内容后缀页。
- 后台壳动作边界矩阵落地，后续动作按字段边界准入。
- 后台壳 smoke 覆盖所有高频动作入口。
- Dcat 最小兼容层审计已落地，旧 `/admin/*` 入口 query string 跳转已有测试护栏。
- 支付异常路径新增签名失败、已完成订单不同交易号重复推进测试，并将维护范围收敛为官方支付宝、官方微信、易支付和 Epusdt。
- 安全专项清单已按已处理、保留过渡、后置复核、需测试补强、需人工配置标注。
- 依赖阻塞矩阵已补 beta.2 状态口径和升级实验分支最小命令集。
- README、当前基线审计、当前进度总汇、执行基线和 release 候选文档口径保持一致。

## 后续版本连接

- `v3.0.0-beta.2`：升级实验准备，不直接升级 Laravel / PHP 大版本。
- `v3.0.0 RC`：候选冻结，只接受回归、安全、测试和文档修正。
- `v3.0.0 stable`：稳定维护入口，标明仍保留的遗留边界和升级实验状态。

## 发布前冻结规则

- 冻结新增高风险功能。
- 只接受阻断级 bug、文档口径修正和测试补强。
- 不删除 `config/admin.php` 或 `routes/admin/routes.php`，除非已有单独验证证明不会破坏后台登录、认证和旧入口跳转。
- 不直接跳 Laravel / PHP 大版本，只完成升级前清障和实验分支准备。
