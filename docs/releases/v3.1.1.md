# 独角数卡西瓜版 v3.1.1 发布说明

发布日期：2026-06-02

版本定位：

- PHP 8.1 / Laravel 8.83 主线上的前台 UI 与移动端购买体验修正版。
- `v3.1.0` 继续作为 PHP 8.1 / Laravel 8 稳定锚点。
- 本版本不新增公开 API，不修改下单字段，不修改支付回调 URL 语义。
- `v3.2.0` 继续作为依赖清障、abandoned 包替换和性能拆包阶段。

## 当前状态

| 项目 | 当前状态 |
| --- | --- |
| Runtime | PHP 8.1+ |
| Framework | Laravel `8.83.29` |
| 前台主题 | `avatar` |
| 重点页面 | 首页、购买页、订单查询页、确认订单页 |
| 支付范围 | 官方支付宝、官方微信、易支付、Epusdt |
| Dcat | 保留过渡兼容层 |

## 主要变化

- 前台购买页完成第三轮精修，方向固定为白灰底、蓝色主操作、橙色价格、青绿色状态提示。
- 移动端购买页改为更紧凑的信息层级：商品摘要、提交订单、商品详情，首屏优先服务下单路径。
- 支付方式 tile 增加 USDT、支付宝、微信的弱色彩区分，选中态仍使用蓝色描边和阴影。
- 接入四张 AI 会员卡封面：月卡、季卡、年卡、终身卡分别使用不同视觉色调。
- 导航 Logo、首页 hero、商品 fallback、支付图标统一从 `public/assets/avatar/images/ui/` 读取。
- 商品详情富文本不清洗数据库，只通过 `.avatar-prose` 降低旧红色、下划线和字号冲突。
- 订单查询页和确认订单页统一到轻量前台视觉，不改变查询地址和支付入口语义。

## 接口边界

- 下单表单 `action` 仍为 `create-order`。
- 购买页字段名保持不变：`gid / email / by_amount / search_pwd / coupon_code / payway / img_verify_code`。
- 订单查询提交地址保持不变：`search-order-by-sn / search-order-by-email / search-order-by-browser`。
- 支付跳转语义保持不变：`pay-gateway/{handle}/{payway}/{orderSN}`。
- 支付回调 URL 和保留支付通道范围不变。
