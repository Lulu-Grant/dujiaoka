# 独角数卡西瓜版 v3.0.0 RC 规划

发布日期：待定

版本定位：

- 正式版前的候选冻结
- 重点是回归修复、安全复核和文档一致性

## 必须满足的状态

- 后台壳主承载冻结，不再新增批量动作。
- 支付异常路径测试稳定。
- 安全专项复核完成。
- Dcat 兼容层职责明确，关键入口不删除。
- README、当前审计、执行基线、release notes、安装文档和升级阻塞矩阵口径一致。

## RC 复核命令

```bash
git diff --check
./scripts/php74 vendor/bin/phpunit
ADMIN_USERNAME=admin-shell-tester ADMIN_PASSWORD=secret123 ./scripts/smoke-admin-shell
```

## RC 搜索复核

- `app/Admin`：只能出现在历史文档或明确历史快照说明中。
- `install.sql`：不得重新进入安装、CI 或测试库准备主路径。
- `admin/admin`：不得作为生产默认账号口径出现。
- `base64:`：不得以真实 `APP_KEY` 示例进入文档或 fixture。
- `PayJS / Vpay / Paysapi`：不得作为新版本维护通道恢复。

## 只接受的变更

- 阻断级 bug 修复
- 安全修复
- 测试补强
- 文档口径修正
