# 独角数卡西瓜版 v3.0.0-rc.1 发布说明

发布日期：2026-06-01

版本定位：

- 正式版前的第一轮候选冻结。
- 不新增功能，只接受回归、安全、测试和文档修正。
- Laravel 7.30.7 桥接已合入主线，但不继续跳 Laravel 8/10 或 PHP 大版本。

## 必须满足的状态

- 后台壳主承载冻结，不再新增后台批量动作。
- Dcat 只作为登录、认证、中间件、权限白名单和旧入口兼容层存在。
- 支付范围固定为官方支付宝、官方微信、易支付和 Epusdt。
- PayPal、Stripe、Coinbase、Mapay、TokenPay、PayJS、Vpay、Paysapi 不恢复。
- 安全专项清单无未解释高风险项。
- 升级实验状态明确：Laravel 7 桥接实验已完成并合入 RC.1，后续 Laravel 8/10、Dcat 退场和 Yansongda 升级继续独立评估。

2026-06-01 复核结论：

- 退役支付通道未回到 `routes/common/pay.php`、`composer.json`、样例种子或当前支付实现文件。
- `app/Admin` 与 `install.sql` 命中均属于历史文档、兼容层审计或防回流测试语境。
- `base64:` 命中仅存在于动态生成逻辑、测试断言或安全审计说明中，未作为发布示例密钥出现。
- 后台支付新增/编辑入口已限制为 `/pay/alipay`、`/pay/wepay`、`/pay/yipay`、`/pay/epusdt`，并拒绝退役支付标识。
- Laravel 7.30.7 已作为 RC.1 主线运行时框架合入；PHP 7.4 继续作为兼容验证运行时，PHP 8.1 继续通过 Docker 验证链路覆盖。
