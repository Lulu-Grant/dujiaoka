# 独角数卡西瓜版 v3.0.0-rc.1 候选清单

发布日期：待定

版本定位：

- 正式版前的第一轮候选冻结。
- 不新增功能，只接受回归、安全、测试和文档修正。
- 不直接升级 Laravel / PHP 大版本。

## 必须满足的状态

- 后台壳主承载冻结，不再新增后台批量动作。
- Dcat 只作为登录、认证、中间件、权限白名单和旧入口兼容层存在。
- 支付范围固定为官方支付宝、官方微信、易支付和 Epusdt。
- PayPal、Stripe、Coinbase、Mapay、TokenPay、PayJS、Vpay、Paysapi 不恢复。
- 安全专项清单无未解释高风险项。
- 升级实验状态明确，不把实验分支内容混入 RC。
