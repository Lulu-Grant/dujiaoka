# 独角数卡西瓜版 v3.2.0 前台资源发布候选

发布日期：2026-06-02

版本定位：

- PHP 8.1 / Laravel 8.83 主线上的前台资源轻量化发布候选。
- 本版本不新增公开 API，不修改下单字段，不修改订单查询提交地址，不修改支付跳转或回调语义。
- 本版本不删除旧静态文件，只停止 `avatar` 前台新页面引用旧重资源。
- 下一阶段 `v3.3` 再进入安全、支付护栏和升级前清障。

| 项目 | 当前状态 |
| --- | --- |

| 核心前台依赖 | `base.css / common.css / index.css / avatar.css / jquery-3.6.0.min.js / hyper.js / SVG-WebP 物料` |

## 资源拆包结果

`avatar` 前台新页面已停止引用：

- `vendor.min.js`
- `app.min.js`
- `bootstrap-input-spinner.js`
- `icons.min.css`
- `bootstrap.min.js`
- `bootstrap.min.css`

旧文件仍保留在静态目录中，原因是历史页面、安装/后台边界、回滚兼容和后续审计仍可能需要引用。本版本只冻结前台新页面引用，不删除历史资源。

## 资源验收记录

本地使用临时前台 fixture 覆盖 `/buy/30-33`，执行完成后已清理 fixture 数据。资源统计按 Playwright headless 本地请求体积估算，浏览器扩展请求不计入。

| 页面 | 最大请求数 | 最大本地资源体积 | 旧重资源命中 |

响应式覆盖 `390px / 430px / 768px / 1440px`。购买页、订单查询页、确认订单页、订单详情页和错误页均未发现横向溢出。首页 `390px` 在全量批量采集中出现一次时序性溢出标记，随后聚焦复核为 `scrollWidth == clientWidth == 390` 且无越界元素。

二维码支付页本轮以模板和脚本语义验证为准：页面继续渲染 `#pay-qrcode`，保留本地二维码插件 `/vendor/dcat-admin/dcat/plugins/jquery-qrcode/dist/jquery-qrcode.min.js`，轮询 `check-order-status/{orderSN}` 和成功后跳转 `detail-order-sn/{orderSN}` 语义不变。

## 交互验收记录

- 首页公告 modal：打开、ESC 关闭通过。
- 订单查询 tab：订单号、邮箱、浏览器缓存 tab 切换通过。
- 购买页购买提示 modal：存在并可关闭。
- 支付 tile：临时 fixture 下 3 个支付方式渲染，点击后 hidden `payway` 从默认值更新为目标支付 ID。
- 购买页校验：空邮箱、数量为 0、超库存均触发前台 toast 防护。
- 订单详情页：详情容器和复制卡密按钮存在。
- 全部已验收页面均未请求旧重资源。

## 接口边界

- 下单表单 `action` 仍为 `create-order`。
- 购买页字段名保持不变：`gid / email / by_amount / search_pwd / coupon_code / payway / img_verify_code`。
- 订单查询提交地址保持不变：`search-order-by-sn / search-order-by-email / search-order-by-browser`。
- 支付跳转语义保持不变：`pay-gateway/{handle}/{payway}/{orderSN}`。
- 支付回调 URL 和保留支付通道范围不变。
