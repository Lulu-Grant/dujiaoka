# 发布稳定路线图

更新时间：2026-05-31

## 目标

本文档把 `v3.0.0-beta.1` 之后的路线拆成可执行阶段，避免在后台壳、支付安全、升级实验和正式稳定版之间来回摇摆。

## 阶段 0：当前现场收口

目标：

- 将 `carmis batch-suffix`、测试和 beta.1 文档包提交为后续基线。

退出标准：

- `.DS_Store` 不进入版本控制。
- `git diff --check` 通过。
- 全量 PHPUnit 与后台壳 smoke 通过。
- 工作区在提交后保持干净。

## 阶段 1：v3.0.0-beta.1

目标：

- 完成后台壳主承载、Dcat 兼容层、支付安全、安全治理和升级阻塞矩阵收口。

必须完成：

- 后台壳动作边界矩阵落地并持续更新。
- `goods / order / pay / coupon / carmis` 高频资源只保留低风险动作。
- Dcat Admin 只作为登录、认证、中间件和旧入口兼容层存在。
- 支付异常路径有测试护栏。
- 安全专项清单每项有处理状态。

冻结规则：

- 不再新增功能。
- 只接受阻断 bug、测试补强和文档口径修正。

## 阶段 2：v3.0.0-beta.2

目标：

- 准备升级实验，但不直接升级 Laravel / PHP 大版本。

必须完成：

- 刷新依赖阻塞矩阵。
- 明确 PHP 小步兼容验证路线。
- 明确 Laravel 桥接版本候选。
- 建立升级实验分支最小命令集。
- 支付范围固定为官方支付宝、官方微信、易支付和 Epusdt，退役通道不再恢复。

退出标准：

- 有可重复的升级实验分支验证清单。
- 失败时可以回到 beta.1 基线。

## 阶段 3：RC 候选

目标：

- 从“继续建设”切换到“候选冻结”。

必须完成：

- 后台壳不再新增批量动作。
- Dcat 仅评估未来可废弃别名，不删除关键兼容入口。
- `.env.example`、fixture、文档示例值和 secret scanning 风险复核完成。
- README、当前审计、执行基线、release notes、安装文档、升级阻塞矩阵口径一致。
- 生成并维护 `docs/releases/v3.0.0-rc.1.md`，作为第一轮 RC 候选清单。

当前状态：

- `docs/releases/v3.0.0-rc.1.md` 已生成。
- 当前测试基线为 `OK (417 tests, 4281 assertions)`。
- `master` 远端 CI 已通过，验证来源为 GitHub Actions `CI` 工作流。
- 支付范围已固定为官方支付宝、官方微信、易支付和 Epusdt，退役通道不恢复。
- RC 前继续只接受回归、安全、测试和文档一致性修正。

## 阶段 4：稳定版前置

只接受：

- 回归修复
- 安全修复
- 安装 / 部署文档修正
- 测试补强

不接受：

- 新支付通道
- 新高风险批量动作
- Laravel / PHP 大版本升级
- 删除 Dcat 兼容关键入口

发布前要求：

- 本地全量 PHPUnit 通过。
- 后台壳 smoke 通过。
- CI 通过。
- release 文档标明仍保留的遗留边界和升级实验状态。
