# Avatar UI Assets

Generated and hand-authored assets for the simplified storefront redesign.

## Raster

- `hero-digital-store.webp`: compact homepage hero illustration, 25 KB.
- `product-digital-card.webp`: generic digital goods product thumbnail, 12 KB.

## SVG

- `logo-mark.svg`: compact brand mark for header experiments.
- `icon-alipay.svg`: Alipay payment tile icon.
- `icon-wechat.svg`: WeChat Pay payment tile icon.
- `icon-usdt.svg`: USDT payment tile icon.
- `icon-order-search.svg`: order search/action icon.
- `icon-secure-delivery.svg`: secure auto-delivery feature icon.

These assets keep the palette on black, white, gray, blue, and orange. They avoid the previous large green/beige visual mass and are intended for the next UI implementation pass.
